Boussole murmurante

Effet :

La boussole murmurante est un charme permettant d'indiquer l'emplacement du chevalier sur la carte.

Utilité :

  • Ce charme est très utlie pour explorer la carte en ayant quasi ou
    peu de connaissances de celle-ci.

  • Il est quand même recommandé d'utiliser une compostion de charmes
    plus orientée vers le combat si vous devez affronter un boss.

  • Ce charme devient inutile une fois que vous avez acquis assez
    de conaissances pour parcourir
    • la région d'Hallownest sans vous repérer.

Localisation :

Ce charme est situé dans la boutique d'Iselda a Dirtmouth pour 220 géos
